## CallGuide — do papel ao aplicativo

Aplicativo Android gratuito para crianças e adultos observarem a escrita cursiva e praticarem seu próprio traço. Digite uma palavra ou nome, acompanhe a animação e desenhe sobre o modelo, com pausa, velocidade ajustável, borracha e palavras favoritas locais. A versão disponível no GitHub funciona offline, sem conta ou anúncios.

A identidade do projeto parte da **Sidiney Caligrafia Refinada**, inspirada na escrita com caneta esferográfica **BIC**.

**[Baixar o aplicativo →](https://github.com/sidineyr/callguid/raw/refs/heads/master/CallGuide.apk)** · [Como instalar](https://github.com/sidineyr/callguid#baixar-e-instalar) · [Baixar a fonte TTF](https://github.com/sidineyr/callguid/raw/80bf6f2d79ac7f85c2d7e68b4855ecf85211bd16/fonts/sidiney-caligrafia/SidineyCaligrafia-Refinada.ttf) · [Publicação no Substack](https://substack.com/home/post/p-223397084)
